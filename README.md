# 🛒 Product Detail UI

A clean and modern **Product Detail Screen** built with Flutter and Dart.

## 📱 Screenshot

![Product Detail Screenshot](assets/images/image.png)

## ✨ Features

- Modern Product Detail UI
- Product image
- Product name and price
- Favorite button
- Increase / decrease product quantity
- Product details section
- Nutritions section
- Customer reviews
- Star rating
- Add To Basket button
- Responsive and scrollable layout

## 🛠️ Technologies

- Flutter
- Dart
- Material Design
